Description

The Maker ESP32 is designed to take the frustration out of building smart electronics and IoT projects. While standard development boards leave you guessing when code fails, this board gives you instant visual and audio feedback right out of the box. Whether you are writing your first lines of code, teaching a classroom, or prototyping a connected device, the Maker ESP32 helps you understand what your board is doing at every step.

With plug-and-play sensor ports, onboard diagnostic lights, and flexible power options, you can focus on bringing your ideas to life without fighting messy jumper wires or complex troubleshooting setups. It also shares a familiar standard pin layout, making it fully compatible with expansion boards like the Robo ESP32 and the NodeMCU ESP32 Expansion Board for easy upgrade and seamless hardware integration.

Warranty Period: 12 months

Features

  • See Your Code in Action: Onboard status LEDs light up instantly to show pin activity and serial data transfer, letting you verify signal flow without needing extra diagnostic gear.
  • Plug-and-Play Expansion: Connect I²C sensors directly using the Maker Port for fast, solderless prototyping compatible with popular sensor ecosystems.
  • Instant Sound & Control: Includes a built-in user button for custom triggers and an onboard buzzer for audio feedback, complete with a physical mute switch when you need to code in silence.
  • Expanded Code Capacity: Powered by an upgraded ESP32-WROOM module that provides extra flash memory space for larger codebases, local web servers, and over-the-air (OTA) wireless updates.
  • Seamless Board Compatibility: Designed around the standard NodeMCU footprint so you can easily drop it into existing projects, codebases, and expansion shields.
  • Modern Power Delivery: Powers and programs via a sturdy, reversible USB Type-C connector, eliminating orientation hassle while delivering reliable power to onboard and external components.

Specification

  • Microcontroller: ESP32-WROOM-32E
  • Processor: Dual-core Xtensa® LX6, up to 240 MHz
  • Wireless Connectivity: Wi-Fi 802.11 b/g/n (2.4 GHz) + Bluetooth 4.2 BLE
  • Flash Memory: 8 MB
  • SRAM: 520 KB
  • Input Voltage (USB-C / VIN): 4.6V – 5.5V DC, 3.3V
  • Onboard Voltage Regulator Output Current: 700mA (Max)
  • Digital Logic Voltage Level: 3.3V
  • Max Output Current per I/O Pin: 40 mA
  • GPIO Diagnostic LEDs: 14 Pins (GPIO 2, 12, 13, 16, 17, 18, 19, 21, 22, 23, 25, 27, 32, 33)
  • Expansion Port: 4-Pin JST-SH Maker Port I2C
  • Onboard Peripherals: User Button (GPIO 4), Piezo Buzzer (GPIO 26) with Mute Switch, BOOT button, RESET button
  • Dimensions: 58.0 mm x 28.4 mm
